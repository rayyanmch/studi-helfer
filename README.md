# Studi-Helfer

Hackathon-Projekt (Deadline: Sonntag Mittag): ein Assistent für Studierende, der ILIAS, Moodle & Co. an einem Ort zusammenführt und mit KI das Organisieren übernimmt.

## Feature-Ideen

- **LMS-Integration**: ILIAS und Moodle anbinden (Kurse, Dateien, Termine, Ankündigungen)
- **Smarter Kalender**: Termine automatisch aus Folien, PDFs und ILIAS/Moodle übernehmen (Abgaben, Klausuren, Übungen)
- **KI-Merkzettel**: Zusammenfassungen und Lernzettel aus Vorlesungsfolien erzeugen
- … weitere Ideen kommen hier rein
